Projet Majeur

Reconstruction & Sécurisation Réseau Multi-VLAN

Déploiement complet d'une infrastructure de laboratoire isolée visant à segmenter, filtrer et superviser les flux critiques d'une architecture d'entreprise. Ce projet s'inspire directement des problématiques techniques rencontrées lors de mon stage chez Concentrix.

Infrastructures Physiques Cisco

  • Cisco 2960 Plus : Procédure de Password Recovery via console, purge complète de la mémoire Flash (vlan.dat) et assignation des ports d'accès.
  • Cisco 9300 (Cœur L3) : Configuration du routage inter-VLAN via SVI et mise en place d'une route statique par défaut vers Internet.
  • Spanning-Tree (Rapid-PVST+) : Élection forcée du Root Bridge (priorité 4096) et sécurisation des ports d'accès via les protocoles PortFast et BPDU Guard.
  • Sécurisation des accès : Filtrage strict des adresses MAC par Port-Security Sticky et chiffrement des flux d'administration via SSHv2.

Sécurité & Filtrage Avancé

  • Hyperviseur Proxmox VE : Activation du mode VLAN Aware sur le pont virtuel Linux pour tagguer correctement les flux 802.1Q des machines.
  • Pare-feu OPNsense : Configuration en mode Default Deny pour un cloisonnement strict (flux DNS 53, Proxy 3128 et SSH 22 explicitement autorisés, le reste est jeté).
  • Proxy Squid & SSL Bump : Filtrage web par catégories basé sur les listes de Toulouse et déchiffrement des flux HTTPS sécurisés à la volée (MitM).
  • Déploiement du Certificat : Automatisation de l'injection du certificat CA sur les postes clients via le fichier de stratégie GPO policies.json.
  • Ajustement HTML : Bourrage artificiel des fichiers HTML des pages de blocage à une taille supérieure à 750 octets pour forcer l'affichage sur Google Chrome et Microsoft Edge.

Supervision Réseau

  • PRTG Network Monitor : Installation logicielle sur l'OS hôte Windows pour contourner l'absence de support d'imbrication de la virtualisation (verrouillage BIOS Intel VT-x).
  • Protocole SNMP v2c : Configuration et sécurisation des agents via une chaîne de communauté personnalisée.
  • Suivi des métriques : Supervision active des commutateurs Cisco (Ping, trafic réseau sur les interfaces de Trunk, RAM et CPU).
